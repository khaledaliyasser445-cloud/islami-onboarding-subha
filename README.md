# Islami App

A Flutter application that brings together Quran reading, Hadith, and a digital Sebha in an Islamic-themed interface.

## Project updates

- Added an onboarding flow and a home screen with navigation for Quran, Hadith, Sebha, Radio, and Time.
- Built the Quran section with Arabic and English surah search, surah details, and a recently opened list saved locally on the device.
- Added a Hadith carousel with 50 locally stored Hadith and a screen for reading each Hadith in detail.
- Added an interactive Sebha counter that rotates with each tap and cycles through three tasbeeh phrases after every 33 counts.
- Added app styling, Arabic fonts, screen artwork, and a native splash screen.

The Radio and Time tabs are currently placeholders.

## Run the app

1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. From the project directory, run `flutter pub get`.
3. Run the app with `flutter run`.
